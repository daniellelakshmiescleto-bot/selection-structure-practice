# Even-or-Odd

## Description
The program checks if the inputted number is even or odd. 

## How to Run
1. Press the button to enter Google Colab from here.
2. Press the play button to run it.
3. Enter a number.

## Input Needed
- number

## Sample Output
'Enter a number: 67
67 is odd.'
